# Module Links Detektor

Links Detektor is a library for detecting and normalizing URLs in text content.

## Available Packages

### com.slothiesmooth.linksdetektor

The main package contains the public API for the Links Detektor library.

* [LinksDetektor][com.slothiesmooth.linksdetektor.LinksDetektor] - The main class for detecting links in text
* [LinksDetektorOptions][com.slothiesmooth.linksdetektor.LinksDetektorOptions] - Configuration options for link detection
* [Url][com.slothiesmooth.linksdetektor.Url] - Represents a detected URL
* [NormalizedUrl][com.slothiesmooth.linksdetektor.NormalizedUrl] - Represents a normalized URL with standardized components
